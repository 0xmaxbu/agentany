# 前端 shell：chat-centric

前端整体信息架构（IA）= chat-centric：chat 是主界面（home），管理功能经「管理」入口进入独立的管理视图。

## 决策

chat 是主 shell（home + 会话列表侧边栏 + 主区 chat）；管理功能（用户/项目/系统/工作流/Skill/定时任务）经一个「管理」入口进入**独立的管理视图**（路由），而非平级 tab、也非双 app。

## 考虑过的备选（未采）

- **后台 shell（平级 tab）**：chat 降格成"功能之一"，违背 CONTEXT「chat 界面 = 主产品面」。
- **分离双 app**：增加部署/维护成本；管理本质是**同一系统的配置面**，不必拆。

## 依据与后果

- 依据：CONTEXT「chat 界面 = 主产品面」+「能力触发走 chat 对话 NL，管理面是查看/配置」→ chat 主、管理从。
- 后果：前端需引入**路由**（chat 主路由 + 管理子路由）；管理入口（侧边栏/顶部）待定。
