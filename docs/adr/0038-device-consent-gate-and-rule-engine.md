# 0038 - 设备侧会话借用授权：分派层统一拦截 + 规则引擎

日期：2026-08-21（grill-with-docs grilling 定稿，Round 1–5）

## 状态

已接受（设计意图）

## 背景

ADR-0033 D7 定了「设备本地弹窗确认」要做，ADR-0035 D3 定了「登录态不出设备」——但**怎么拦、什么粒度、规则可否调整、拒绝后服务端怎么办**从未设计。本轮 grill 同时确认了既有缺口：PRD US 4–6（env 探测/补全）客户端侧未实现；PRD 措辞与 ADR-0035 D2 有矛盾残留。用户核心诉求：**每一次工具调用都可以拦截询问，具体规则用户可调整**；服务端只提供 API/协议字段，UI 全在客户端。

## 决策

**D1 · 统一拦截点在客户端 dispatcher**：所有 `tool_call` 过 gate——架构上任何工具都可被拦截；**出厂默认只对会话借用类**（`browser.*` 六件套 + `computer_use.*` 三件套，动的是设备用户登录态/桌面）弹窗询问，标准五件套不拦（接入配置的信任提示已明示「该服务器可在此设备执行任意命令」）。

**D2 · `tool_call` 协议加 `workflowId`**：按工作流的授权粒度需要稳定标识，`runId` 每次执行新开（当粒度=每次都问，不可用）。服务端 `DeviceToolRpc` 按 runId 查 run 补值。改动链 = ws-protocol 单一真相源 → server 补值 → mock-server 跟改 → r6 集成 seam 锚定（正是 #9 定的漂移契约机制）。

**D3 · 规则引擎（四档 × 三层）**：
- 策略：`ask_every`（每次问）/ `ask_first`（首次问，同意后记住）/ `allow` / `deny`（命中直接回拒绝，不弹窗）。
- 层级：全局默认（borrow=`ask_first`、rest=`allow`）→ 例外规则（`workflowId × tool × host` 覆盖，缺维度=全局，**细粒度优先**）→ remembered（弹窗产生，工作流作用域）。
- 存储：`~/.agentany/grants.json`（0600，与 client.json 同口径）。

**D4 · 「参数敏感」锚点三分支**（「总是允许」默认参数敏感——同样操作不再问）：
- `browser.*`：工作流 × **工具面(browser) × host**——六件套共享站点授权（允许在 github.com 导航，点击/输入自然跟随）；host **后缀匹配**（`github.com` 覆盖子域），忽略 scheme/port/path。
- `computer_use.*`：工作流 × 工具面（坐标每次都变，无有意义参数锚点）。
- 标准五件套（用户调规则要问时）：工作流 × tool × **args 精确等值**（canonical JSON 比对；bash 命令串天然适用）。

**D5 · 弹窗四选 + 超时**：`本次允许`（仅当前 callId）/ `总是允许`（参数敏感，写 remembered）/ `总是允许该工具`（参数不敏感，**本工作流内**该工具一律放行——全局放行只能经授权管理显式编辑规则，不是弹窗一键）/ `拒绝`。无响应 60s 视为拒绝。决策经 `onConsent` 回调抽象注入——无头可测（测试注入假实现），Tauri 壳实现真弹窗；P7 无头授权=换一个 consent 实现。

**D6 · 拒绝的服务端语义 = 纯透传**：deny 回 `tool_result {ok:false, code:"denied", error:"denied by device user: … 请勿重试同一工具，改用其他路径"}`——**run 不中止、不自动重试、不转 HITL**：deny 是设备用户的明确决定而非故障，错误文案即服务端处理（LLM 读它改道）。**卡死收尾**：LLM 确认无法推进后 run 失败（每次 denied 已在 run 日志，可诊断）；恢复 = 设备用户放开授权 + **远端用户手动重跑**（与「设备掉线→run 失败→人工处理后重跑」同构，零新机制）。
对照：`env_remediated approved:false` 发生在 run **开始前** → 服务器有动作（pending_start 不续跑）；工具 deny 发生在 run **进行中** → 服务器无动作。时点不同，语义不同。

## 负决策

- **否决服务端执行授权策略**：服务器无法验证设备真的弹了窗——授权必须发生在被借用资源所在的一侧。
- **否决 run 中途挂起等授权**（deny→挂起→同意→续跑）：需要新 run 状态 + 中途挂起存储，冲撞 PRD Out of Scope「断点续跑不做」；摩擦高频再立项。
- **否决 deny 转 HITL/IM 循环**：把授权摩擦升级成对话循环（ADR-0033 IM 负决策先例）。
- **否决 path 级 URL 匹配**：对授权语义无增益且极脆（SPA 路由随时变）。
- **否决弹窗一键全局放行**：全局放宽必须是显式编辑规则的动作。
- **否决 web 运行详情高亮 denied（v1）**：将来加一个 run 事件即可，不占 v1。
