# learnings — 经验文档

沉淀每次跑工作流的经验：踩坑、结论、证据、适用场景。**结论必须有证据，不凭假设沉淀。**

## 文件命名

`learnings/<主题>.md`，例如 `learnings/pi-工作流写法.md`

## 格式

- **结论** —— 一句话
- **证据** —— 为什么这么判断（日志/复现/数据/文档引用）
- **为什么** —— 背后的原因
- **适用场景** —— 什么时候适用，什么时候不适用
- **相关** —— 关联工作流/其他经验（`[[name]]` 链接）

## 提升为 skill 的门槛

一条经验反复用到、且能写成稳定步骤时，提升到 `skills/`。见 `skills/README.md`。
