# brand-research —— 调研方法论

本 skill 是 **brand-research 工作流**的执行深度指引：怎么把调研做深、把角度做出独到性。**阶段顺序 / 产出文件 / suspend / 循环由代码管**（编排），本 skill 管**怎么思考**（方法论）。

## 三层证据（把信息分三层、分开标注）

- **[F] 事实**：数据 / 来源可查
- **[P] 感知**：市场 / 消费者对品牌的**认知**（即使与事实不符，也是关键情报——认知即现实）
- **[I] 推断**：基于前两层的分析判断（须写明依据）

多数平庸报告只有 F+I。**有深度必须抓 [P]**——事实与感知的落差往往是最大机会。

## 分析透镜（至少深入运用 2-3 个）

1. **认知-现实落差**：实际事实 vs 市场认知 → 落差即机会（有资产没认知=低估）或风险（有认知没支撑=透支）
2. **资产-战略错配**：现有资产 vs 战略意图 → 错配处=升级最大杠杆
3. **品牌-品类关联**：品牌是否=品类第一联想、品类定义权
4. **战略矛盾诊断**：品牌同时追求的冲突目标 → 矛盾的解法=升级主线
5. **竞品空白矩阵**：定位×能力×心智 三维空白
6. **消费者决策旅程**：决策哪个环节流失 / 触点失语

## 调研五块（每条带来源 URL、按 [F]/[P]/[I] 标注）

1. **行业基本面**：规模/增速/趋势/渠道/新锐动向；**地区市场**规模与本地特点
2. **竞争格局与市场占有率**：3-5 个直接竞品——定位/视觉/渠道/价格带、**门店数/市占率**；地区竞争态势；竞品**战略意图**
3. **品牌差异分析**：目标品牌 vs 竞品在 定位/产品/价格/视觉/渠道/心智 上的差异点与空白
4. **品牌诊断**（挖机制）：定位/产品线/视觉资产/渠道/认知 + **战略沿革根因**（反复变脸/摇摆的根因）+ **消费者口碑**（[P] 主要来源）
5. **消费者**：目标客群（含地区）/ 需求 / 决策因素 / 未被满足诉求

写到 `brand-research/<brand>-<region>/research-report.md`。

## 产出角度（3-5 个，宁少而深）

每个角度必须满足**独到性门槛**（至少一个非显而易见洞察）：无人认领资产 / 战略矛盾 / 品类重定义 / 竞品盲区。找不到独特洞察的不进候选。

每个角度含：标题 / 核心洞察（注明哪类独到性）/ 战略逻辑（[F][P]→[I] 证据链）/ 机制分析（为什么成立）/ 逻辑验证（条件/反例/可行性）/ 设计工作范围（**不给具体设计样式**）/ 可行性。

**写 `brand-research/<brand>-<region>/angles.json`**（机读，供战略分析步按 id 选择）：
```json
[
  { "id": 1, "title": "战略方向短语", "insight": "独到洞察（注明类别）",
    "evidence": ["[F] ... (url)", "[P] ... (url)"], "logicValidation": "条件/反例/可行性", "feasibility": "高|中|低" }
]
```

## 规则

- 结论必有证据（来源 URL），三层证据分离，不编造。
- 深度优先：挖机制、回答 So what，宁少而深。
- 所有调研走 `web_search`/`web_extract`/`web_crawl`，不编造。
- **focus（定向重跑）**：若输入带 focus，读已有 `research-report.md` 后**补研/扩展**该方面，不从头重来；angles.json 同步更新。
- 中文输出。
- 工具报错（key 缺/配额）→ 报告错误并停。
