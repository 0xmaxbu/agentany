# 品牌战略升级调研工作流

业务背景：为**品牌设计、包装、视觉系统**的设计及制作服务客户。**分析必须深入、独到、专业**——不是行业报告的复述，而是为客户提供别人给不了的洞察。

## 工具

- `web_search(query, max_results?)` — Tavily 搜索，返回标题/URL/内容摘要
- `web_extract(urls[])` — 提取网页正文（深读官网/报告/竞品页）
- `web_crawl(url, max_depth?, limit?)` — 爬取站点
- 内置 `read`/`write`/`edit`/`bash` — 读写文件、建目录

## 深度分析方法论（先读）

这是本工作流的灵魂。产出质量取决于是否真正执行以下方法：

### 三层证据
把信息分为三层，**分开标注**：
- **[F] 事实**：数据/来源可查
- **[P] 感知**：市场/消费者对品牌的**认知**（即使与事实不符，也是关键情报——认知即现实）
- **[I] 推断**：基于前两层的分析判断（必须写明依据）

多数平庸报告只有 F+I。**有深度的报告必须抓 [P]**——事实与感知的落差往往是最大机会。

### 分析透镜（至少用 2-3 个，深入运用）
1. **认知-现实落差**：品牌的实际事实（规模/品质/供应链）vs 市场认知 → 落差即机会（有资产没认知=低估）或风险（有认知没支撑=透支）
2. **资产-战略错配**：品牌现有资产（品类地位/视觉资产/供应链/心智/渠道）vs 公司战略意图 → 错配处 = 升级的最大杠杆
3. **品牌-品类关联**：品牌是否=品类第一联想（"XX=品类"），品类的定义权在谁手里，能否重新定义品类
4. **战略矛盾诊断**：品牌同时在追求的相互冲突的东西（如低价走量 vs 高端溢价、大众 vs 精品、快速扩张 vs 心智沉淀）→ 矛盾的解法 = 战略升级主线
5. **竞品空白矩阵**：定位×能力×心智 三维空白 —— 竞品有能力没位置、有位置没能力、有心智没资源的地方
6. **消费者决策旅程**：在决策的哪个环节流失/未被满足，品牌在哪个触点失语

### 独到性门槛
每个切入角度必须基于**至少一个非显而易见的洞察**，例如：
- **无人认领的资产**：品牌有、但没人意识到/没被使用的资产
- **战略矛盾/张力**：品牌自己都没说破的内部矛盾
- **品类重定义机会**：重新框定品类边界（扩大或聚焦）的可能
- **竞品集体盲区**：所有对手都没看到的机会

找不到独特洞察的角度不进候选。**宁可角度少而深，不要多而浅。**

### 机制深度
- 诊断写**"为什么会这样"**（机制/根因），不写"是什么"（现象）
- 每个结论回答 **"So what"**：这意味着什么、影响什么决策
- 用数据支撑论断，不堆形容词

## 阶段

### 1. 输入

- 参数：`/skill:brand-strategy-research <品牌名> [地区]`
- `<品牌名>` 必填；`<地区>` 可选，**缺省为"重庆"**
- 品牌+地区是研究范围；输出目录用 `<品牌>-<地区>` 或 `<品牌>`

### 2. 调研（web_search + web_extract，必要时 web_crawl）

调研 5 块，**每条信息带来源 URL**，按三层证据标注（[F]/[P]/[I]）：

1. **行业基本面**：市场规模/增速/趋势、结构、渠道格局、新锐品牌动向；**地区市场**（重庆）：规模、增长、本地消费特点
2. **竞争格局与市场占有率**：3-5 个直接竞品/头部品牌——定位、视觉语言、包装、渠道、价格带、**门店数/市占率**；地区内（重庆）竞争态势；竞品的**战略意图**（扩张/升级/降价等动作）
3. **品牌差异分析**：目标品牌 vs 竞品在 定位/产品/价格/视觉/渠道/心智 上的差异点与空白（差异化机会）
4. **品牌诊断**（要挖到机制）：
   - 定位/产品线/价格带/视觉资产/包装/渠道/消费者认知
   - **品牌战略沿革**：定位/形象几次切换、并购、财务变化 → 找出"反复变脸"或"摇摆"的根因
   - **消费者口碑**：真实评价/吐槽/社媒讨论（[P] 层的主要来源）
5. **消费者**：目标客群画像（含地区）、需求、购买决策因素、未被满足的诉求

写调研笔记到 `.work/brand-research/<brand>/research-notes.md`：分节、每条带来源 URL、按 [F]/[P]/[I] 标注。

### 3. 产出切入角度（深入 + 逻辑验证）

按"深度分析方法论"综合，产出 **3-5 个**高质量角度（宁少而深）。每个角度含：

- **标题**：一个战略方向短语
- **核心洞察**：本角度最独到、非显而易见的洞察是什么（无人认领资产/战略矛盾/品类重定义/竞品盲区，注明是哪一类）
- **战略逻辑**：完整证据链 —— [F]/[P] 证据（注明来源）→ [I] 推断 → 机会点
- **机制分析**：为什么这样能成立（深层原因，不是表面关联）
- **逻辑验证**：假设成立条件？反例？与其它证据矛盾？可行性/风险？
- **设计工作范围**：需要设计/制作哪些工作项 + 要解决的战略问题（**不得给出具体设计样式**）
- **服务范围映射**：对应我们可提供的设计与制作服务项
- **可行性**：成本/风险/见效速度（高/中/低）

角度维度参考：品牌定位重塑 / 视觉识别(VI)焕新 / 包装体系升级 / 超级符号·视觉锤 / 客群聚焦与调性重塑 / 品类占位与差异化视觉 / 渠道场景化视觉适配 / 品牌叙事与信任感建立。

**验证要求**：每个角度必须满足独到性门槛（有非显而易见的洞察）+ 逻辑自洽（证据链完整、无反例、不与调研矛盾）。写 `angles.md` 并**完整展示给用户**（含核心洞察与逻辑验证摘要）。

### 4. 用户选择

- 在 Pi 会话中向用户提问，**结束当前回合等待回复**："请回复要深入的角度编号（可多选，如 1,3,5），或回复'全部'。"
- 用户回复后解析编号并保存到 `.work/brand-research/<brand>/selection.md`。

### 5. 生成报告

按选定角度生成 `reports/<品牌>-<地区>品牌战略升级报告.md`，结构：

1. **执行摘要**
2. **核心洞察**（报告灵魂）：2-3 个最独到、最专业的发现，每个说明"为什么别人没看到/没想到"，附 [F]/[P] 依据 —— 这是与泛泛咨询报告拉开差距的部分
3. **调研发现**：行业（含地区）/ 竞争与市场占有率 / 品牌差异 / 品牌诊断（含机制）/ 消费者
4. **品牌机会点**（经逻辑验证）
5. **选定角度深化**：每个角度一节 —— 核心洞察 → 战略逻辑（证据链）→ 机制分析 → **逻辑验证** → 设计工作范围 → 服务范围映射 → 预期效果
6. **视觉识别系统工作范围**：需设计什么、解决什么战略问题（不给具体样式）
7. **包装设计工作范围**：同上
8. **服务范围与交付**：把核心建议映射到我们的服务项，说明每项交付什么、如何推进
9. **落地路线与优先级**（阶段/里程碑/验收标准）

规则：每个结论带来源标注，三层证据分离，方案必须经过逻辑验证；写入后向用户报告路径。

## 报告红线（重要）

**报告是战略交付物，不是设计方案。** 具体设计样式是设计师的工作，报告一律**不得出现**：具体配色（色值/色相/主色名）、具体字体/字形/字标方案、具体图形/符号/IP 造型、具体工艺（烫金/双层杯/专色等）/材质/版式、任何"应该长什么样"的表述。

报告中设计相关内容只允许写**工作范围与目标**："需要建立一套支撑 X 定位的视觉识别体系 / 需要重构包装体系以解决 Y 问题"，具体方案由设计团队在后续设计阶段提案。一旦报告预设样式，客户会对实际设计产生**不符合现实的预期**，因此红线必须遵守。

## 规则

- **结论必须有证据**（来源 URL）；按 [F]/[P]/[I] 三层标注，不编造数据
- **深度优先**：挖机制、找独特洞察、回答 So what；宁少而深，不堆砌
- **所有方案必须逻辑验证**：证据链完整、无反例、不与调研矛盾
- 调研区域以输入地区（缺省重庆）为研究重点之一
- 所有调研走 `web_search`/`web_extract`/`web_crawl`，不编造
- 中文输出（客户为中文语境）
- 若搜索工具报错（如 key 缺失/配额不足），报告错误并停止，提示用户检查 `.env` 的 `TAVILY_PROXY_API_KEY`
- 目录 `.work/`、`reports/` 不存在则先 `mkdir -p`
- 跑完后提示可把本次经验沉淀到 `learnings/`
